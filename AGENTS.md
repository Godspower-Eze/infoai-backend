# Project Guidelines

## Workflow

- Break implementation into reviewable steps. Complete one step, report changes, files, validation, and issues, then wait for approval before commit.
- Optimize for correctness over speed. Combine steps only when explicitly requested.
- Read-only planning exploration may be grouped.

## Design

- Follow SOLID, emphasizing S, O, I, and D. Apply L when substitution is relevant.
- Prefer composition and focused interfaces. Avoid speculative abstractions.
- Less code is better.
